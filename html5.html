HTML / 03

Što je HTML?

Jezik za označavanje sadržaja.

HTML znači HyperText Markup Language. Opisuje strukturu web-stranice: što je naslov, odlomak ili poveznica. Nije programski jezik za pisanje algoritama.

HTML / 04

Oznaka ≠ element

<p>Učim izrađivati web-stranice.</p>
  • <p> — početna oznaka.
  • Tekst između oznaka — sadržaj.
  • </p> — završna oznaka.
  • Cijela prikazana cjelina — HTML element.

Prazni elementi, poput <br> i <img>, nemaju završnu oznaku.

Probaj usmeno označiti početak, sadržaj i završetak elementa naslova.

HTML / 05

Kostur HTML dokumenta

<!DOCTYPE html>
<html lang="hr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Moja prva stranica</title>
</head>
<body>
  <h1>Pozdrav, svijete!</h1>
  <p>Ovo je moja prva HTML stranica.</p>
</body>
</html>

Deklaracija <!DOCTYPE html> označava suvremeni HTML dokument. lang="hr" označava hrvatski jezik.

HTML / 06

Head i body: dvije različite uloge

<head>

Podaci o dokumentu.

  • title: naziv kartice preglednika.
  • charset="UTF-8": kodiranje znakova.
  • viewport: postavka prikaza na mobilnim uređajima.

<body>

Sadržaj koji se prikazuje na stranici.

  • Naslovi i tekst.
  • Slike i poveznice.
  • Popisi i obrasci.
Pitanje: zašto promjena elementa title ne mijenja veliki naslov u sadržaju?

HTML / 07

Prvi praktični korak

  1. Otvori uređivač teksta, primjerice VS Code.
  2. Napravi mapu moja-stranica.
  3. U njoj spremi dokument kao index.html.
  4. Upiši kostur s prethodnog slajda.
  5. Otvori datoteku u pregledniku.
  6. Promijeni naslov, spremi datoteku i osvježi preglednik.
Uspjeh: kartica preglednika ima tvoj naziv, a stranica prikazuje tvoj naslov i odlomak.

HTML / 08

Naslovi i odlomci

<h1>Moj projekt</h1>
<h2>O projektu</h2>
<p>Izrađujem svoju prvu web-stranicu.</p>
<h2>Što učim?</h2>
<h3>HTML elementi</h3>
<p>Učim označavati sadržaj.</p>

Naslovi imaju šest razina: h1 do h6. Biraj ih prema hijerarhiji sadržaja, a ne samo prema veličini slova.

Za ovu vježbu koristi jedan glavni h1, a cjeline označi s h2.

HTML / 09

Ugnježđivanje i isticanje

<p>HTML učimo <strong>praktičnim radom</strong>.</p>
<p>Ovo je <em>posebno naglašena</em> riječ.</p>
<!-- Ovaj komentar nije vidljiv na stranici. -->

strong označava važnost, a em naglasak. Element unutar drugog elementa zatvori prije vanjskog elementa.

<p>Ispravno: <strong>važan tekst</strong>.</p>
Pronađi pogrešku: <p><strong>Tekst</p></strong>

HTML / 10

Atributi: dodatne informacije

<a href="https://www.w3schools.com/html/">Učimo HTML</a>

Atribut se piše u početnoj oznaci, najčešće kao naziv="vrijednost". Ovdje href određuje odredište poveznice.

  • lang — jezik dokumenta.
  • href — odredište poveznice.
  • src — putanja do resursa.
  • alt — tekstualna alternativa slici.
  • id — jedinstveni identifikator elementa u dokumentu.

Za dosljednost piši nazive malim slovima i vrijednosti stavljaj u navodnike.

HTML / 11

Poveznice i putanje

<a href="https://www.w3schools.com/html/">HTML dokumentacija</a>
<a href="kontakt.html">Kontakt</a>
<a href="#hobi">Moji hobiji</a>

<h2 id="hobi">Moji hobiji</h2>
  • Apsolutna adresa uključuje protokol i domenu.
  • Relativna putanja upućuje na datoteku u odnosu na trenutačni dokument.
  • #hobi vodi do elementa s odgovarajućim id.
Koristi opisni tekst poveznice, primjerice „HTML dokumentacija”, umjesto „klikni ovdje”.

HTML / 12

Slike i alternativni tekst

<img src="slike/radionica.jpg"
     alt="Učenici spajaju elektronički sklop u radionici"
     width="600" height="400">

Za ovaj primjer sliku spremi u podmapu slike. Naziv, nastavak i putanja moraju odgovarati stvarnoj datoteci.

alt prenosi smisao slike kada slika nije dostupna i korisnicima čitača zaslona. Za isključivo dekorativnu sliku koristi se prazan alt="".

Dijagnostika: ako slika ne radi, provjeri putanju, velika i mala slova te nastavak .jpg / .png.

HTML / 13

Popisi: grupiranje sadržaja

<h2>Moji interesi</h2>
<ul>
  <li>Programiranje</li>
  <li>Računalne mreže</li>
</ul>

<h2>Kako otvoriti stranicu?</h2>
<ol>
  <li>Spremi dokument.</li>
  <li>Otvori ga u pregledniku.</li>
</ol>

ul je neuređeni popis, ol uređeni popis, a li pojedinačna stavka.

HTML / 14

Semantička struktura

<header>
  <h1>Web-klub</h1>
</header>
<nav><a href="#o-nama">O nama</a></nav>
<main>
  <section id="o-nama">
    <h2>O nama</h2>
    <p>Učimo izrađivati web-stranice.</p>
  </section>
</main>
<footer><p>Projekt</p></footer>

Semantički elementi opisuju ulogu sadržaja: zaglavlje, navigaciju, glavni sadržaj, tematsku cjelinu i podnožje. Sami po sebi ne stvaraju složen vizualni raspored.

HTML / 15

Dodatno: prvi obrazac

<form action="/prijava" method="post">
  <label for="ime">Ime:</label>
  <input type="text" id="ime" name="ime" required>
  <button type="submit">Prijavi se</button>
</form>
  • for u oznaci label odgovara atributu id polja.
  • name određuje naziv podatka koji se šalje.
  • required označava obavezno polje.
HTML stvara obrazac, ali ne obrađuje ni ne sprema podatke. Adresa /prijava je samo primjer: potrebna je stvarna poslužiteljska obrada.

HTML / 17

Samostalni zadatak: moja stranica

Izradi stranicu o sebi, projektu ili omiljenom hobiju. Predloženo vrijeme: 20 minuta.

  • Ispravan kostur dokumenta, lang="hr", UTF-8 i smislen title.
  • Jedan glavni naslov, barem dva podnaslova i dva odlomka.
  • Popis s najmanje tri stavke.
  • Poveznica s opisnim tekstom.
  • Vlastita slika ili slika koju smiješ koristiti, s odgovarajućim alt tekstom.
  • Uredna struktura s glavnim sadržajem i podnožjem.

HTML / 18

Prije predaje: testiraj

  1. Provjeri naziv kartice i glavni naslov — nisu isti element.
  2. Otvori sve poveznice i provjeri sliku.
  3. Provjeri zatvaranje i ugnježđivanje oznaka.
  4. Prođi poveznicama tipkom Tab.
  5. Suzi prozor i provjeri čitljivost.
  6. Zamoli kolegu da prema kodu objasni strukturu stranice.
Preglednik može prikazati i neispravan HTML. „Izgleda dobro” nije isto što i „kod je ispravan”.
