01
          
Što je CSS?

        

        
CSS (Cascading Style Sheets) je jezik kojim opisujemo kako HTML elementi trebaju izgledati na
          ekranu.

        
Ako dolaziš iz "običnog" programiranja, razmišljaj ovako: HTML je struktura podataka (što
          postoji na stranici), a CSS je prezentacijski sloj (kako to izgleda). CSS nije programski
          jezik s petljama i uvjetima, nego deklarativan jezik: ti kažeš što želiš, a preglednik odluči
          kako to nacrtati.

        

          

            
HTML

            
Sadržaj i struktura: naslovi, odlomci, slike, gumbi.
kostur
          

          

            
CSS

            
Izgled: boje, fontovi, razmaci, raspored, animacije.
odjeća
          

          

            
JavaScript

            
Ponašanje: klikovi, podaci, logika.
mišići
          

        

        
Zašto "CSS3"?

        
CSS3 je naziv za modernu generaciju CSS-a. Umjesto jedne velike specifikacije, podijeljen je u
          module (boje, fontovi, Flexbox, Grid, animacije...) koji se razvijaju zasebno. Zato danas
          imaš zaobljene rubove, sjene, gradijente, varijable i animacije bez ijedne slike ili linije JavaScripta.
        

        
Zašto "cascading" (kaskadni)?
          
Više pravila može ciljati isti element. Preglednik ih slaže po važnosti, specifičnosti i redoslijedu, a
            kasnije pravilo s istom težinom pobjeđuje. O tome više u lekciji 4.

02
          
Kako dodati CSS na stranicu

        

        
Postoje tri načina. U stvarnim projektima gotovo uvijek koristiš vanjsku datoteku.

        

          

            
1. Vanjski (external)

            
Zasebna .css datoteka povezana s <link>. Jedna datoteka za cijeli web.
            
preporučeno
          

          

            
2. Unutarnji (internal)

            
Unutar <style> oznake u <head>. Dobro za jednu stranicu ili brzi
              test.
ponekad
          

          

            
3. Inline

            
Atribut style="" na samom elementu. Teško za održavanje.
izbjegavaj
          

        

        

          
index.html

          
<!DOCTYPE html>
<html lang="hr">
<head>
  <!-- 1. Vanjski CSS -->
  <link rel="stylesheet" href="style.css">

  <!-- 2. Unutarnji CSS -->
  <style>
    h1 { color: navy; }
  </style>
</head>
<body>
  <!-- 3. Inline CSS -->
  <p style="color: red;">Crveni tekst</p>
</body>
</html>

        

        
Redoslijed je bitan
          
Ako isti element dobije stil s više mjesta, inline stil ima najveću prednost, a između vanjskog i
            unutarnjeg pobjeđuje onaj koji je kasnije naveden u <head>.

03
          
Sintaksa: anatomija pravila

        

        
Svako CSS pravilo ima selektor (koga stiliziramo) i blok deklaracija u
          vitičastim zagradama. Svaka deklaracija je par svojstvo: vrijednost;.

        

          
h1 { color: blue; font-size: 12px; }

          

            selektor
            svojstvo (property)
            vrijednost (value)
          

        

        

          
style.css

          
/* Ovo je komentar — preglednik ga ignorira */
p {
  color: red;          /* boja teksta */
  text-align: center;  /* poravnanje */
}

        

        
Probaj sam: promijeni vrijednosti lijevo i rezultat se odmah osvježava desno.

        

          
          
        

        
Najčešća greška
          
Zaboravljena točka-zarez ; između deklaracija. Preglednik neće javiti grešku, samo će tiho
            ignorirati pokvareno pravilo.

Specifičnost: tko pobjeđuje?

        
Kad više pravila cilja isti element, pobjeđuje specifičnije. Pojednostavljeno: inline stil
          > ID > klasa / pseudo-klasa > element. Ako je specifičnost ista, pobjeđuje pravilo napisano kasnije.
        

        

          
specifičnost

          
p          { color: black; }  /* 0-0-1 */
.tekst     { color: green; }  /* 0-1-0 — pobjeđuje element */
#glavni    { color: blue;  }  /* 1-0-0 — pobjeđuje klasu */

        

        
Savjet
          
Za stiliziranje koristi gotovo isključivo klase. ID-jeve ostavi za JavaScript i sidra (linkove na dio
            stranice). Tako izbjegavaš "ratove specifičnosti" i potrebu za !important. Uvođenjem
            important-a u naš CSS kod narušili smo pravila specifičnosti

05
          
Boje, pozadine i jedinice

        

        
Boju možeš zapisati na više načina. Svi daju isti rezultat, a izbor je stvar navike.

        

          
boje

h1 { color: rgba(255, 99, 71, 0.5); }  /* RGB + prozirnost */

06
          
Box model: sve je kutija

        

        
Ovo je najvažniji koncept u CSS-u. Kad ga shvatiš, 80% problema nestaje.

        
Svaki HTML element je pravokutna kutija sastavljena od četiri sloja, iznutra prema van:

        
    
          
  • content — sam sadržaj (tekst, slika)
    • 
          
  • padding — unutarnji razmak, između sadržaja i ruba. Ima boju pozadine elementa
    • 
          
  • border — rub oko paddinga
    • 
          
  • margin — vanjski razmak, odmiče druge elemente. Uvijek proziran
    • 
        

        

          
Interaktivni box model

Zamka: box-sizing

        
Po zadanom (content-box) width se odnosi samo na sadržaj, pa padding i border
          povećavaju stvarnu širinu. To zna biti zbunjujće u početku. Rješenje koje može biti od
          pomoći: stavi ovo na vrh svoje CSS datoteke.
        

        

          
reset.css

          
*, *::before, *::after {
  box-sizing: border-box;  /* width uključuje padding i border */
}

        

        

          
kratki zapis (shorthand)

          
margin: 10px;                /* sve četiri strane */
margin: 10px 20px;           /* gore/dolje  lijevo/desno */
margin: 10px 20px 30px 40px; /* gore desno dolje lijevo (u smjeru kazaljke) */
margin: 0 auto;              /* centriraj blok element vodoravno */

08
          
Pozicioniranje

        

        
Svojstvo position određuje kako se element smješta i radi li na njega top,
          right, bottom, left.
        

        

          

            
              

                Vrijednost
                Ponašanje
              

            
            
              

                static
                Zadano. Element je u normalnom toku, top/left ne rade
              

              

                relative
                Pomak u odnosu na svoje normalno mjesto. Često služi kao "sidro" za apsolutnu djecu
              

              

                absolute
                Izvan toka. Pozicionira se prema najbližem pozicioniranom pretku
              

              

                fixed
                Prema prozoru preglednika, ne miče se pri pomicanju stranice
              

              

                sticky
                Ponaša se kao relative dok ne dosegne zadanu poziciju, zatim se "zalijepi"
              

            
          

        

        

          
          
        

        
Pravilo palca
          
Za raspored stranice (stupci, redovi, centriranje) nemoj koristiti position.
            Za to služe Flexbox i Grid. Pozicioniranje čuvaj za značke, padajuće izbornike, ljepljiva zaglavlja i slične
            sitnice.

09
          
Flexbox: raspored u jednoj dimenziji

        

        
Flexbox slaže elemente u red ili stupac i rješava poravnanje i raspodjelu prostora.

        
Postaviš display: flex na roditelja (flex kontejner), a njegova izravna djeca
          postaju flex elementi. Ključno je razumjeti dvije osi: glavnu os (određuje je
          flex-direction) i poprečnu os (okomita na glavnu).
        

        
    
          
  • justify-content — poravnanje po glavnoj osi
    • 
          
  • align-items — poravnanje po poprečnoj osi
    • 
          
  • flex-wrap — smiju li elementi prijeći u novi red
    • 
          
  • gap — razmak između elemenata
    •

10
          
Grid: raspored u dvije dimenzije

        

        
Dok Flexbox radi u jednom smjeru, CSS Grid istovremeno upravlja redovima i stupcima. Idealan
          je za raspored cijele stranice ili galerije.

        

          
header — grid-column: 1 / 3

          
aside

          
main

          
footer

        

        

          
raspored stranice

          
.stranica {
  display: grid;
  grid-template-columns: 1fr 3fr;  /* 2 stupca: 1 dio + 3 dijela */
  grid-template-rows: auto 1fr auto;
  gap: 8px;
}
header, footer {
  grid-column: 1 / 3;  /* od linije 1 do linije 3 = preko oba stupca */
}

        

        
Jedinica fr (fraction) znači "dio slobodnog prostora". Probaj galeriju koja se sama prilagođava
          širini:

        

          
          
        

        
Flexbox ili Grid?
          
Flexbox kad slažeš stvari u liniju (navigacija, gumbi, ikona + tekst). Grid kad trebaš
            mrežu s redovima i stupcima (raspored stranice, galerija, kartice). Često se koriste
            zajedno.

12
          
CSS varijable (custom properties)

        

        
Programerima je ovo poznato: vrijednost definiraš jednom i koristiš je posvuda. Varijable počinju s
          --, a čitaju se funkcijom var(). Definirane u :root vrijede za cijeli
          dokument.
        

        

          
          
        

        
Zašto je to korisno?
          
Tamna tema, brendirane boje, jedinstveni razmaci... Sve se mijenja na jednom mjestu. Varijable se mogu
            mijenjati i iz JavaScripta: element.style.setProperty('--glavna', 'teal').

13
          
Prijelazi, transformacije i animacije

        

        
CSS3 zna animirati bez JavaScripta. Tri alata, od najjednostavnijeg:

        

          

            

            
transition

            
Glatka promjena kad se stanje promijeni. Prijeđi mišem.

          

          

            

            
transform

            
Pomak, rotacija, skaliranje. Prijeđi mišem.

          

          

            

            
@keyframes

            
Animacija koja se vrti sama, bez interakcije.

          

        

        

          
transition + transform

          
.kutija {
  transition: transform 0.4s ease, background-color 0.4s;
}
.kutija:hover {
  transform: scale(1.2) rotate(10deg);
  background-color: tomato;
}

        

        

          
          
        

        
Performanse
          
Animiraj prvenstveno transform i opacity. Preglednik ih radi na grafičkoj
            kartici, pa su glatke. Animiranje width, top ili margin tjera
            preglednik da ponovno izračuna raspored i može trzati.

14
          
Responzivni dizajn i media queries

        

        
Stranica mora dobro izgledati i na mobitelu i na monitoru. Dva su preduvjeta:

        
    
          
  1. Viewport meta oznaka u <head>. Bez nje mobitel prikazuje umanjenu
            verziju desktop stranice.
    2. 
          
  2. Media queries — CSS pravila koja vrijede samo pod određenim uvjetima, npr. kad je zaslon
            širi od 768px.
    3. 
        

        

          
index.html

          
<meta name="viewport" content="width=device-width, initial-scale=1.0">

        

        

          
mobile-first pristup

          
/* Zadano: mobitel — jedan stupac */
.kartice {
  display: grid;
  grid-template-columns: 1fr;
}

/* Tablet i šire */
@media (min-width: 600px) {
  .kartice { grid-template-columns: 1fr 1fr; }
}

/* Desktop */
@media (min-width: 900px) {
  .kartice { grid-template-columns: repeat(3, 1fr); }
}

Mobile-first

            jednostavniji jer mobilni raspored je obično najjednostavniji.
